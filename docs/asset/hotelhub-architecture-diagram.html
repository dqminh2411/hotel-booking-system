Kiến trúc hệ thống HotelHub

Microservices & Database

  • 7 microservices nghiệp vụ, mỗi service một PostgreSQL DB riêng.
  • Place Booking Service điều phối Saga đặt phòng / thanh toán / khuyến mãi.
  • Redis dùng để cache và chống race condition khi đặt phòng & áp dụng coupon.
  • Kafka dùng cho các command / event bất đồng bộ giữa các service.

Gateway & Service Discovery

  • Gateway route request tới từng service theo Eureka discovery.
  • Gateway & mỗi service gửi OTLP traces về OTel Collector.

Xác thực

  • Frontend xác thực trực tiếp với Keycloak.
  • API Gateway xác thực JWT qua JWKS của Keycloak.
  • Các service cũng dùng JWKS để xác thực JWT cho phân quyền API.

Observability

  • Gateway & mọi service gửi OTLP traces + audit logs về OTel Collector.
  • Traces chuyển tiếp sang Jaeger, Jaeger ghi vào Elasticsearch; audit logs ghi vào Elasticsearch index audit-logs-*.
  • Kibana trực quan hóa audit log dashboard từ Elasticsearch.
